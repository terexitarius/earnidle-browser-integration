EarnIdle Browser Container

Browser-native EarnIdle inference and capability examples. Each capability runs fully in-browser with no compile step.

Capability examples

  • Bandwidth / routing (HTTP, WebSocket, WebRTC)
  • CPU (JS / WebAssembly compute)
  • GPU via WebGPU / WebGL
  • Memory / caching
  • Temporary storage (IndexedDB, Cache API)
  • Micro-sensors / RTC (camera/mic)
  • EarnIdle VM — browser compute node
